# Context Management

- Never read entire large files unless explicitly necessary.
- Search for relevant symbols before opening files.
- Read files in focused chunks (150-250 lines).
- Limit command output. Use grep, head, tail, and targeted filters.
- Never dump entire logs, dependency trees, or generated files.
- Delegate independent exploration only when it reduces duplicated context.
- Keep a concise progress summary in a project file for long tasks.
- Before compaction, summarize current findings, decisions, and remaining work.
- After compaction, continue from that summary instead of repeating exploration.
